# GLOSSARY

Domain terminology and core concepts for Ayeraa Save Downloader:

- **Ayeraa Save Downloader**: Multi-platform media downloader (desktop & mobile) supporting TikTok, Instagram, YouTube, X/Twitter, Spotify, Facebook, and more.
- **Client-Side Scraper Engine**: Direct HTTP-based scraper logic executing in the browser or mobile WebView (Capacitor) without server-side transcoding requirements.
- **shadcn/ui**: Modern component system built on React, Tailwind CSS, and Radix UI primitives.
- **Capacitor**: Cross-platform native runtime enabling web applications to run natively on Android/iOS with direct access to filesystem and system APIs.
- **In-App Auto-Update**: Seamless updating of an installed Android application in-place without requiring manual uninstallation or loss of app data.
- **Persistent Signing Keystore**: Cryptographic certificate ensuring all consecutive APK distributions share an identical identity, satisfying Android package manager compatibility checks.
- **Tracer Bullet**: Thin end-to-end slice through all architectural layers.
